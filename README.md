# ValoSensTester（无畏契约灵敏度测试工具）

用科学方法找到你的最佳游戏内灵敏度：基于论文级瞄准测试范式 + 贝叶斯优化，10 分钟给出推荐值（精确到 0.001）与训练建议。

## 功能特性

- **单文件免安装**：109MB 单 exe，下载即玩，无需安装
- **贝叶斯灵敏度推荐**：粗扫 4 点 + 高斯过程建模 + 高原修正，推荐精确到 0.001，附 95% 置信区间；信号过弱时如实告知"无显著差异"
- **论文级测试范式**：每靶仅一次单击判定（命中/失败/超时），"没中就是没中"，拒绝虚高命中率
- **瞄准效率评分**：评分已剥离灵敏度物理差异（归一化轨迹效率），同一灵敏度内越快得分越高，跨灵敏度公平比较
- **多维度诊断**：成功率 / 中位命中耗时 / 每靶微调次数 / 失败耗时（区分出手太快与慢而打偏）/ 轮间稳定性（仿真校准阈值）/ 长距·短距分组分析
- **训练建议**：针对识别出的问题给出对应练习方向（预瞄 / 拉枪 / 跟枪 / 节奏控制）
- **历史记录与趋势**：本地保存最近 100 次测试，灵敏度与效率分趋势图、与上次对比
- **多模式**：标准 / 压力 / 追踪（移动靶，含跟枪精度）/ Flick
- **数据隐私**：全部数据本地存储，无网络上传

## 快速开始

1. 从发布页下载 `ValoSensTester.exe`
2. 双击运行（首次启动需 1-2 秒解包，属正常现象）
3. 设置你的 DPI 与测试参数 → 开始测试
4. 每轮约 1 分钟，跑 10 轮（建议）后查看推荐灵敏度

> **SmartScreen 提示**：软件使用自签名证书，Windows 可能提示"未知发布者"，点击"更多信息 → 仍要运行"即可。

## 测试流程

选择 → 配置（灵敏度范围/轮数/目标大小/模式）→ 射击（热身 12 靶 + 正式轮次）→ 结果页

- 每靶**只允许单击一次**：准星在靶内点击 = 命中；未中 = 失败（立即进入下一靶）；3 秒未出手 = 超时
- 灵敏度建议范围 0.1~0.9（游戏内灵敏度 × DPI = eDPI）
- 推荐做 2~3 次完整测试收敛后再定实战灵敏度

## 评分与推荐原理

```
每靶得分 = 1/(1 + t×sens/θ)    失败/超时 = 0 分
轮得分   = mean(每靶得分) × 稳定性系数(1/(1+命中耗时MAD/中位数))
```

- 命中耗时先**扣除暂停/系统休眠污染**（异常时长 >3s 自动剔除）
- 高斯过程回归（噪声 σ_n=0.08 经 200 轮蒙特卡洛仿真校准）拟合灵敏度-得分曲线
- 推荐 = 曲线峰值 ± 高原修正（有多个数据点支撑的实测高点优先，排除孤立噪声尖峰）

## 常见问题

| 问题 | 说明 |
|---|---|
| 命中耗时异常大（几十秒） | 测试期间系统休眠/锁屏会污染计时，程序已自动剔除 >3s 的异常耗时；建议测试期间关闭自动休眠 |
| 推荐 0.001 精度有意义吗 | 曲线平坦时差异在噪声内，结果页会明确提示"无显著差异"，此时按手感选择即可 |
| 移动靶/追踪模式下微调为 0 | 设计如此：追枪反向移动不算定位微调 |
| 杀软误报 | 未签名的 Godot 导出程序偶被误报，自签名后已大幅减少；可加白名单 |
